# English with Daria - сайт преподавателя английского

Сайт Дарьи Канниццаро: https://darya-english.com
React 19 + Vite + Tailwind CSS v4 + Motion. Код в GitHub `4tdesign/darya-english`, ветка `main`.
Vercel автоматически публикует каждый push в `main` (проект `darya-english`).

## Жёсткие правила владельца (соблюдать всегда)

- Никаких эмодзи/смайликов. Нигде: ни в текстах сайта, ни в коде, ни в сообщениях.
- Только короткое тире "-". Никогда не использовать длинное "—" и среднее "–" (в том числе в диапазонах: "15-20", "A1-B2").
- Не публиковать (git push в main) без явного разрешения владельца.

## Где что лежит

- `src/content.ts` - ВСЕ тексты сайта на двух языках (`en` и `ru`). Любую правку текста делать в обоих языках.
- `src/components/Hero.tsx` - первый экран
- `src/components/Stats.tsx` - тёмный блок с цифрами
- `src/components/Club.tsx` - клуб «Кружка английского» (тетрадный лист в клетку)
- `src/components/Sections.tsx` - О преподавателе, Курсы, Цитата, Отзывы, Контакты, Подвал, мобильная кнопка
- `src/components/Pen.tsx` - «красная ручка»: подчёркивания, зачёркивания, галочки, рукописные пометки
- `src/components/Nav.tsx` - шапка и переключатель RU/EN
- `src/components/Booking.tsx` - страница записи `/book` (форма, кнопки Telegram с готовым текстом и ВК с копированием)
- `vercel.json` - чтобы адрес `/book` открывался напрямую
- `src/index.css` - цвета, шрифты, кнопки
- `src/imports/` - фотографии

## Дизайн

- Цвета: бумага `#faf7f0`, чернила `#1c1a17`, красная ручка `#c8173a` (единственный акцент), клетка тетради `#9db8d9`.
- Шрифты (локальные, без Google): Unbounded - заголовки (класс `display` / `font-display`); Onest - основной текст; Caveat - только красные рукописные пометки.
- Анимации: «красная ручка» (рисуется один раз при появлении), сценарий загрузки первого экрана, мягкие цветные круги на фоне, «живое» фото Дарьи (`src/imports/daria-live.mp4`, играет один раз и возвращается к фото, при наведении мышью повторяется).
- Учитывать `prefers-reduced-motion`.

## Команды

- `npm run dev` - локальный просмотр
- `npm run build` - проверка типов и сборка в `dist/`
